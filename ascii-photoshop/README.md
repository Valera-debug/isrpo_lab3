Решение принимается в виде PR из ветки `livecoding`.
Разрешается пользоваться только cppreference, любые другие источники, включая ваш прошлый код, запрещены!


## Задача

Реализовать консольное приложение **ASCII Photoshop** для обработки изображений, состоящих из текстовых символов.

Изображение представляет собой прямоугольную матрицу символов. Программа должна прочитать исходное изображение из файла, последовательно выполнить команды, переданные строкой в аргументе командной строки, и записать результат в выходной файл.

Приложение должно принимать три позиционных аргумента командной строки:

* **IMAGE** — путь к файлу исходного изображения.
* **COMMANDS** — строка с последовательностью команд.
* **OUTPUT** — путь к файлу для записи результата.

Аргументы передаются в строгом порядке: `./app IMAGE COMMANDS OUTPUT`.

## Формат данных

### Изображение

В первой строке файла исходного изображения записаны два целых числа — `height width`, высота и ширина изображения. Далее следуют `height` строк, каждая из которых содержит ровно `width` символов.

Например:

```text
3 4
ABCD
EFGH
IJKL
```

Размеры исходного изображения положительные. Изображение содержит только печатные ASCII-символы, кроме пробела.

Формат выходного файла совпадает с форматом файла исходного изображения: сначала высота и ширина полученного изображения, затем его строки.

### Команды

Строка команд состоит из символов `H`, `V` и `R` без пробелов. Каждый символ задаёт одну операцию. Количество команд отдельно не указывается.

Например: `"RHV"`.

| Команда | Описание |
|---------|----------|
| `H` | Отразить изображение слева направо |
| `V` | Отразить изображение сверху вниз |
| `R` | Повернуть изображение на 90° по часовой стрелке |

Команды выполняются слева направо. Каждая команда применяется к результату предыдущей операции. Команды могут повторяться: например, `"RR"` поворачивает изображение на 180°.

## Операции

### Горизонтальное отражение

Команда `H` отражает изображение относительно вертикальной оси. Размеры изображения не изменяются.

```text
ABC      CBA
DEF  ->  FED
```

### Вертикальное отражение

Команда `V` отражает изображение относительно горизонтальной оси. Размеры изображения не изменяются.

```text
ABC      GHI
DEF  ->  DEF
GHI      ABC
```

### Поворот

Команда `R` поворачивает изображение на 90° по часовой стрелке. Высота и ширина меняются местами.

```text
ABC      DA
DEF  ->  EB
         FC
```

## Пример

Запуск программы:

```sh
./app image.txt "RHV" output.txt
```

**image.txt**

```text
3 4
ABCD
EFGH
IJKL
```

После выполнения всех команд файл **output.txt** должен содержать:

```text
4 3
DHL
CGK
BFJ
AEI
```

## NB

* Можно считать, что содержимое входного файла и строка команд соответствуют описанному формату, а все команды корректны.
* Если строка команд пустая (`""`), в выходной файл записывается исходное изображение.
* Если входной файл не удалось открыть или результат не удалось записать, программа должна вывести сообщение об ошибке и завершиться с кодом `1`.
* При успешном выполнении программа завершается с кодом `0`.

## Ограничения

Запрещается использовать контейнеры стандартной библиотеки, включая `std::vector`, `std::array` и `std::string`.
