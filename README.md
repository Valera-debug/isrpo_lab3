## Описание
Плагин для среды разработки CLion, предназначенный для учета рабочего времени и сбора статистики активности разработчика в процессе написания кода.

## Возможности плагина
* Отслеживание времени, затраченного на работу.
* Подсчет количества сборок проекта (build).
* Подсчет количества запусков программы (run).
* Сброс текущих показателей времени и счетчиков.
* Отображение статистики в интерфейсе IDE.
